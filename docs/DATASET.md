# Данные проекта

## 1. Источники

| Набор | Файл | Период | Назначение |
|-------|------|--------|------------|
| Синтетика (обучение) | `data/synthetic_sales.csv` | 2023-11-10 – 2025-11-08 | обучение модели |
| Синтетика (тест) | `data/holdout_sales.csv` | 2025-11-09 – 2026-11-08 | честная проверка |
| Агрегаты по дням | `data/synthetic_daily.csv`, `data/holdout_daily.csv` | — | графики и сравнение |
| Реальные данные | `data/real/cashier_data.csv` | 2016-12-12 – 2020-08-31 | внешний референс |
| База данных | `db.sqlite3` | — | рабочее хранилище |

Сырые CSV можно перегенерировать командами:

```powershell
python manage.py generate_sales
python manage.py import_real_data
```

`db.sqlite3` в репозиторий не попадает: база создаётся командами
`migrate` и `bootstrap_demo`.

## 2. Структура синтетических продаж

`data/synthetic_sales.csv`:

| Колонка | Тип | Описание |
|---------|-----|----------|
| `date` | date | день продажи |
| `sku` | string | артикул товара |
| `product_name` | string | название |
| `category` | string | категория |
| `quantity` | int | продано, шт. |
| `revenue` | decimal | выручка, ₽ |
| `dataset` | string | `train` или `holdout` |
| `is_peak` | bool | попадает ли день в праздничное окно |
| `holiday_name` | string | название пика |
| `promo` | bool | была ли акция |
| `expected` | float | математическое ожидание до шума |

Один день × один товар = одна строка. Всего:

- обучение: 730 × 16 = **11 680** строк;
- тест: 365 × 16 = **5 840** строк.

## 3. Генератор

Код: `shop/forecasting/synthetic.py`, параметры товаров —
`shop/forecasting/constants.py`.

### 3.1. Формула

```
q = base × trend × weekday × month × holiday × promo × noise
```

### 3.2. Недельная сезонность

Откалибрована по реальному датасету и нормирована к среднему 1:

| Пн | Вт | Ср | Чт | Пт | Сб | Вс |
|----|----|----|----|----|----|----|
| 0.797 | 0.742 | 0.806 | 0.866 | 1.148 | 0.961 | 1.678 |

Воскресенье — самый сильный день, вторник — самый слабый.

### 3.3. Годовая сезонность

| Месяц | Коэф. | Месяц | Коэф. |
|-------|-------|-------|-------|
| Янв | 0.85 | Июл | 0.90 |
| Фев | 1.05 | Авг | 0.95 |
| Мар | 1.12 | Сен | 1.12 |
| Апр | 1.00 | Окт | 1.02 |
| Май | 1.05 | Ноя | 0.95 |
| Июн | 0.95 | Дек | 1.00 |

### 3.4. Праздничные пики

| Дата | Праздник | Коэф. спроса | Окно разгона |
|------|----------|:------------:|:------------:|
| 14.02 | День всех влюблённых | 2.6 | 10 дней |
| 23.02 | День защитника Отечества | 2.0 | 7 дней |
| 08.03 | Международный женский день | 3.2 | 14 дней |
| 01.09 | День знаний | 2.0 | 7 дней |
| 05.10 | День учителя | 1.5 | 5 дней |

Разгон описывается степенью 1.35: чем ближе праздник, тем сильнее эффект.
После праздника остаётся короткий хвост 18%.

### 3.5. Шум и тренд

- AR(1) с коэффициентом 0.25 создаёт плавные колебания;
- обучение: шум σ = 0.16, тренд 4%/год, seed 42;
- тест: шум σ = 0.22, тренд 6%/год, seed 2026,
  праздничные коэффициенты ослаблены до 88%, спрос повышен на 6%.

Разные seed и режимы не дают модели «выучить» тестовый год.

## 4. Внешний реальный датасет

Файл: `data/real/cashier_data.csv`.

Колонки: `Date`, `CutFlowers`, `PotOwn`, `PotPurchased`, `Wholesale`,
`FruitVegs`, `Commodity`, `MeanTemp`, `MeanHumidity`, `PublicHoliday`,
`SchoolHoliday`.

Для сравнения используется `CutFlowers` — дневная выручка от срезанных
цветов. После импорта данные лежат в `RealMarketRecord`.

Особенности:

- 1 359 наблюдений, 1 128 ненулевых дней;
- Германия, 2016–2020;
- нет российских праздников;
- есть пропуски и нулевые дни — при сравнении они отбрасываются.

Датасет **не участвует в обучении**, поэтому сравнение не создаёт утечки.

## 5. Сравнение синтетики и реальных данных

| Метрика | Значение | Вывод |
|---------|----------|-------|
| Корреляция недельного профиля | 0.996 | отличное совпадение ритма |
| Корреляция месячного профиля | 0.072 | профили расходятся из-за праздников |
| KS-статистика | 0.2185 | распределения различаются |
| p-value | < 0.001 | различие значимо |
| CV синтетики / реальных | 0.783 / 0.815 | сопоставимая вариабельность |

Высокая недельная корреляция — главный показатель правдоподобности.
Низкая месячная корреляция объяснима: в синтетике есть пики 23 февраля,
8 марта и 1 сентября, которых нет в немецком датасете.

## 6. Воспроизводимость

- все случайные потоки используют `numpy.random.default_rng(seed)`;
- даты обучения и теста вычисляются от текущей даты на момент генерации;
- параметры моделей и метрики сохраняются в `ModelRun` и `ModelMetric`;
- выгрузка метрик: `python manage.py export_metrics` → `docs/metrics.json`,
  `docs/metrics.csv`.

Чтобы полностью повторить стенд:

```powershell
python manage.py migrate
python manage.py bootstrap_demo
python manage.py export_metrics
```
