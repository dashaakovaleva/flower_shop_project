# Информационная система управления цветочным магазином с прогнозированием спроса

Учебный проект по дисциплине «Информационные системы и технологии».  
Кафедра прикладной информатики, 3 курс, 1 семестр.

---

## О проекте

Информационная система автоматизирует ключевые бизнес-процессы розничного цветочного магазина:

- учёт товаров, категорий, поставщиков;
- оформление и обработка заказов клиентов;
- контроль остатков на складе;
- прогнозирование спроса на пиковые даты (14 февраля, 23 февраля, 8 марта, 1 сентября, 5 октября);
- поддержка принятия решений по закупкам для менеджера.

Система реализует ролевую модель (клиент, менеджер, администратор) и предоставляет дашборд с прогнозами и рекомендациями.
