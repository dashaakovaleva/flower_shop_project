# 🌷 FloraIS — информационная система цветочного магазина с прогнозированием спроса

Учебный проект по дисциплине **«Информационные системы и технологии»**.
Реализована полноценная информационная система розничного цветочного магазина:
каталог и заказы, склад и поставки, ролевая модель, аналитика, прогноз спроса
на праздничные пики и рекомендации по закупкам.

> **Стек:** Python 3.12, Django 6.1, Django REST Framework, SQLite, pandas, NumPy,
> statsmodels (SARIMAX), Plotly. Интерфейс — Django Templates + собственный CSS
> в зелёно-золотой палитре, графики работают офлайн (локальный `plotly.min.js`).

## Быстрый старт

### Windows (PowerShell)

```powershell
cd flower_shop_project
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

python manage.py migrate
python manage.py bootstrap_demo
python manage.py runserver
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py bootstrap_demo
python manage.py runserver
```

Откройте <http://127.0.0.1:8000/>.

> `bootstrap_demo` выполняет всё сразу: справочники, 2 года синтетики,
> импорт внешнего реального датасета, демонстрационные заказы, бэктест
> и рабочий прогноз. Обучение SARIMAX занимает 3–5 минут.
> Быстрый вариант без обучения: `python manage.py bootstrap_demo --skip-training`.

## Что умеет система

### Клиент
- каталог с поиском, фильтрами по категориям и сортировкой;
- карточка товара, корзина в сессии, оформление заказа;
- личный кабинет с историей заказов и отменой заказа;
- автоматический возврат остатков на склад при отмене.

### Менеджер
- дашборд: выручка, количество продаж, средний чек, рост к прошлому периоду;
- управление заказами и статусами (новый → в обработке → готов → выполнен);
- управление товарами, ценами, остатками и минимальным запасом;
- регистрация поставок с автоматическим увеличением остатка;
- прогноз спроса на 7 дней и рекомендации по закупке;
- аналитика качества модели: MAE, RMSE, MAPE, WAPE, смещение, покрытие интервала;
- анализ ошибок I и II рода;
- сравнение синтетических данных с внешним реальным датасетом.

### Администратор
- всё, что доступно менеджеру;
- Django Admin для управления всеми сущностями;
- доступ к административным разделам интерфейса.

### REST API
Полноценный API на Django REST Framework: каталог, заказы, продажи,
пиковые даты, запуски моделей, прогнозы, рекомендации и аналитика.
Интерактивная документация доступна по адресу `/api/`.
Подробное описание — в [docs/API.md](docs/API.md).

## Прогнозный модуль

### Данные
- **Обучение:** 2 года (730 дней) синтетических продаж по 16 товарам.
- **Тест:** 3-й год (365 дней), сгенерированный отдельным случайным потоком
  с другим seed, уровнем шума, трендом и праздничными коэффициентами.
- **Внешний реальный датасет:** `data/real/cashier_data.csv`
  (розничный цветочный магазин, 2016-12-12 – 2020-08-31) — используется
  только для сравнения профилей спроса, не для обучения.

### Модель
Основная модель — **SARIMAX(1,0,1)(1,0,1,7)** с экзогенными признаками:

- день недели (6 дамми, понедельник — база);
- 3 гармоники Фурье для годовой сезонности;
- абсолютный тренд (непрерывный между обучением и прогнозом);
- ramp-признаки праздников: разгон, сам день, короткий хвост;
- признак промо-акции.

При ошибке обучения автоматически используется резервная
**сезонная лог-линейная регрессия** с теми же признаками.

### Пиковые даты
14 февраля, 23 февраля, 8 марта, 1 сентября, 5 октября.
Для каждой задаётся коэффициент спроса и окно разгона.

### Рекомендации по закупке
```
прогноз спроса за 7 дней × (1 + страховой запас 15%)
    − текущий остаток = рекомендуемая закупка
```
Приоритет зависит от покрытия остатком требуемого запаса:
`< 50%` — критичный, `< 75%` — высокий, `< 95%` — средний, иначе низкий.

### Фактические метрики бэктеста

| Сегмент | MAE | RMSE | MAPE | WAPE | Смещение | Покрытие 80% интервала |
|---------|-----|------|------|------|----------|------------------------|
| Все дни | 3.16 | 11.01 | 22.68% | 23.33% | +7.72% | 62.0% |
| Обычные дни | 2.36 | 3.93 | 21.97% | 20.34% | +4.21% | 63.3% |
| Пиковые дни | 8.16 | 28.08 | 27.15% | 31.88% | +17.76% | 53.8% |

**Ошибки I/II рода (высокий спрос):**
FP = 365, FN = 177, precision = 71.6%, recall = 83.9%, accuracy = 90.7%.

**Ошибки I/II рода (дефицит на 7 дней):**
FP = 115, FN = 11, precision = 45.0%, recall = 89.5%, accuracy = 84.9%.

**Сравнение синтетики с реальными данными:**
корреляция недельного профиля — **0.996**, месячного — 0.072,
KS-статистика — 0.2185. Высокая недельная корреляция подтверждает, что
генератор воспроизводит реальный ритм спроса; расхождение по месяцам
объясняется российскими праздниками, которых нет в немецком датасете.

Подробный отчёт — в [docs/REPORT.md](docs/REPORT.md).
Сырые метрики — в [docs/metrics.json](docs/metrics.json) и [docs/metrics.csv](docs/metrics.csv).

## Management-команды

| Команда | Назначение |
|---------|-----------|
| `python manage.py seed_reference` | категории, товары, поставщики, пользователи, клиенты, пиковые даты |
