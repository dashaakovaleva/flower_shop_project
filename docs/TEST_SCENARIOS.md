# Сценарии тестирования FloraIS

## Автоматические тесты

```powershell
.\venv\Scripts\python.exe manage.py test shop.tests -v 2
```

Ожидаемый результат: `Ran 36 tests ... OK`.

| Модуль | Что проверяет |
|--------|---------------|
| `test_orders.py` | списание и возврат остатков, атомарность, поставки, пустой заказ |
| `test_roles_api.py` | редиректы, 403 для клиента, доступ менеджера, регистрация, REST API |
| `test_metrics.py` | MAE/RMSE/MAPE/WAPE, ошибки I/II рода, сравнение данных |
| `test_synthetic.py` | размер генерации, пики, периоды, признаки, тренд |
| `test_models_forecasting.py` | свойства моделей, пиковые даты, regression-backend |

## Ручные сценарии

### 1. Регистрация и вход

1. Открыть `/register/`, заполнить форму.
2. Ожидается редирект на главную и создание `Customer`.
3. Войти как `client/client123`.
4. В боковом меню видны «Каталог», «Корзина», «Мои заказы».

### 2. Оформление заказа

1. Открыть `/catalog/`, добавить товар в корзину.
2. Перейти в `/cart/`, изменить количество.
3. Нажать «Оформить заказ».
4. Заполнить адрес, дату, тип клиента.
5. Ожидается редирект на `/orders/{id}/`, статус «Новый».
6. Проверить, что остаток товара уменьшился на количество заказа.

### 3. Отмена заказа

1. Открыть карточку заказа.
2. Нажать «Отменить заказ».
3. Ожидается статус «Отменён» и возврат остатка.
4. Повторная отмена недоступна.

### 4. Нехватка товара

1. Войти менеджером, уменьшить остаток товара до 0.
2. Клиентом добавить товар в корзину.
3. Ожидается сообщение «доступно только 0 шт.» и товар не добавляется.

### 5. Роли

1. Клиентом открыть `/dashboard/`, `/forecast/`, `/analytics/`.
2. Ожидается страница 403.
3. Менеджером открыть те же страницы — 200.
4. Клиентом открыть чужой заказ `/orders/{чужой_id}/`.
5. Ожидается редирект на главную с сообщением об отказе.

### 6. Управление заказом

1. Менеджером открыть `/manager/orders/`.
2. Изменить статус заказа: новый → в обработке → готов → выполнен.
3. Проверить, что клиент видит новый статус в «Моих заказах».

### 7. Поставки

1. Открыть `/manager/supplies/`.
2. Создать поставку на 10 единиц.
3. Проверить, что остаток товара увеличился на 10.
4. Проверить запись в списке поставок.

### 8. Прогноз

1. Менеджером открыть `/forecast/`.
2. Выбрать товар или «Все товары».
3. Ожидается график истории и прогноза с 80% интервалом.
4. В таблице — 7 дней, пиковые даты выделены.
5. В рекомендациях — приоритет, остаток, прогноз, закупка.
6. Нажать «Построить прогноз» — создаётся новый запуск.

### 9. Аналитика

1. Открыть `/analytics/`.
2. Проверить карточки MAE, RMSE, MAPE, WAPE, смещения, покрытия.
3. Проверить таблицу ошибок I/II рода и per-product метрики.
4. Переключить запуск в выпадающем списке.
5. Нажать «Запустить бэктест» — новый запуск (3–5 минут).

### 10. Сравнение данных

1. Открыть `/analytics/comparison/`.
2. Проверить KS-статистику, корреляцию недельного и месячного профиля.
3. Проверить графики «Синтетика vs реальные данные».

### 11. REST API

```powershell
# публичный каталог
curl http://127.0.0.1:8000/api/products/

# заказ клиента
curl -u client:client123 -H "Content-Type: application/json" `
  -d '{"items":[{"product":1,"quantity":1}],"delivery_address":"Москва"}' `
  http://127.0.0.1:8000/api/orders/

# метрики менеджера
curl -u manager:manager123 http://127.0.0.1:8000/api/analytics/metrics/

# клиенту аналитика запрещена → 403
curl -u client:client123 http://127.0.0.1:8000/api/analytics/metrics/
```

### 12. Администратор

1. Войти как `admin/admin123`.
2. Открыть `/admin/`.
3. Проверить редактирование товаров, заказов, запусков модели.
4. Убедиться, что клиент не видит ссылку на Django Admin.

### 13. Проверка качества кода

```powershell
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\venv\Scripts\python.exe manage.py test shop.tests
```

Ожидается: `System check identified no issues`, `No changes detected`,
все тесты пройдены.

## Негативные проверки

| Ситуация | Ожидаемое поведение |
|----------|---------------------|
| Пустая корзина | редирект в каталог с сообщением |
| Количество ≤ 0 | ошибка валидации |
| Заказ больше остатка | `StockError`, остатки не меняются |
| Отмена выполненного заказа | кнопка недоступна |
| Повторное открытие отменённого заказа | проверка остатка и повторное списание |
| Клиент открывает чужой заказ | отказ и редирект |
| Аноним открывает приватную страницу | редирект на `/login/?next=...` |
| Неверный логин/пароль | форма с ошибкой, без 500 |
| Неизвестный URL | страница 404 |
| Нет прав на API | 403 JSON |
| Бэктест не запускался | 404 JSON / заглушка на странице |
